# Contribuindo com o projeto

## Padrões de código

- nomes claros e consistentes
- funções e variáveis em snake_case
- evitar duplicação
- responsabilidade identificável
- tratar entradas inválidas

## Verificações

- executar o programa
- executar o Pylint
- corrigir ou justificar
- realizar o commit

## Ferramentas

Pylint · pre-commit · Git
